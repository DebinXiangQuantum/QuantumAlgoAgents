# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the plugin follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html). QADL and search-space versions are maintained separately as data-contract versions.

## [Unreleased]

### Fixed

- Configure explicit pip cache dependency paths for GitHub Actions.

## [0.1.1] - 2026-07-18

### Added

- Original light, dark, and composer brand assets with editable SVG sources.
- Detailed English and Simplified Chinese project documentation.
- Architecture, QADL-IR, and scientific claim policies.
- Apache-2.0 licensing and open-source community health files.
- GitHub issue forms, pull request template, and remote CI workflow.
- Packaging tests for manifest version and referenced brand assets.

### Changed

- Expanded Codex plugin metadata and starter prompts.
- Replaced non-public `.local` JSON Schema identifiers with stable project URNs.
- Clarified that the MCP server is SDK-free rather than dependency-free.
- Made complete QADL validation fail closed when `jsonschema` is unavailable.

## [0.1.0] - 2026-07-18

### Added

- Eight evidence-gated Codex skills for quantum and hybrid algorithm design.
- QADL-IR 0.1 and finite search-space JSON Schemas.
- Deterministic validation, resource analysis, formal rendering, search, and advantage audit.
- Random and evolutionary Pareto search.
- Optional Gymnasium and Stable-Baselines3 PPO/MaskablePPO exploration.
- CLI, stdio MCP server, Grover examples, and regression tests.
