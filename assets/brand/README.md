# Brand assets

The Quantum Algorithm Designer mark combines three project ideas in one compact symbol:

- a branching graph for finite algorithm-space exploration;
- a highlighted path and phase arc for quantum candidate selection;
- a diamond evidence gate that every claim must cross.

It deliberately avoids atom, brain, globe, and generic sparkle motifs. The mark contains no text, gradient, shadow, trademark, or third-party artwork and remains legible at composer-icon scale.

## Files

- `mark-light.svg`: editable light-background source.
- `mark-dark.svg`: editable dark-background source.
- `logo.png`: 1024 px light-mode plugin logo rendered from `mark-light.svg`.
- `logo-dark.png`: 1024 px dark-mode plugin logo rendered from `mark-dark.svg`.
- `composer-icon.png`: 256 px light mark for compact Codex surfaces.
